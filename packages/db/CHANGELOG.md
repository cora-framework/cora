# @cora-framework/db

## 0.1.0

### Minor Changes

- 8372c8f: Initial release of @cora-framework/db - a typed database client for CORA built on Kysely. Provides configuration resolution from environment variables, database handle creation for MySQL (mysql2) and SQLite (better-sqlite3), forward-only migration management with checksum verification, transaction support, and test database helpers. Usable standalone in any CyberMP project without the CORA framework.
